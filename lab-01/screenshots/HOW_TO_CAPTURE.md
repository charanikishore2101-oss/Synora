# screenshots/

This folder is reserved for screenshots of the four Express endpoints.

## How to capture screenshots

1. Start the Express server:
   ```bash
   cd lab-01
   npm start
   ```

2. Open each URL in your browser and press **Win + Shift + S** (Windows Snip)
   or use the built-in browser screenshot tool.

3. Save the screenshots with these exact filenames:

   | Endpoint               | URL                          | Save As          |
   |------------------------|------------------------------|------------------|
   | Home                   | http://localhost:3000/       | home.png         |
   | About                  | http://localhost:3000/about  | about.png        |
   | Time                   | http://localhost:3000/time   | time.png         |
   | 404 Not Found          | http://localhost:3000/invalid| not-found.png    |
