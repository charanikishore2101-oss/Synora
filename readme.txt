SYNORA — Personal Productivity Companion
"Everything you need. One shortcut away."

Overview:
SYNORA is a desktop-first productivity assistant inspired by Apple Spotlight, Raycast, Linear, Arc Browser, and Windows 11 Fluent Design.

Features:
- Spotlight Companion Popup (Ctrl + Space)
- Unified Single Search List across Web, Notes, Clipboard, Vault, Calculator, and Commands
- Smart Clipboard Timeline with color swatch previews & category filters
- Instant Link Vault bookmarking via URL drag & drop or paste (Ctrl + V)
- Scientific & Standard Expression Calculator
- Pomodoro Focus Studio
- Windows 11 Desktop Demo Scene launch experience
- 60 FPS Framer Motion shared layout transitions

Keyboard Shortcuts:
- Ctrl + Space / Cmd + Space: Toggle SYNORA Spotlight Companion
- Ctrl + K: Open Global Command Palette
- Ctrl + Enter: Expand into target workspace
- Escape: Minimize workspace / Exit to Desktop Demo Scene
